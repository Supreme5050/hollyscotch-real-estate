# HOLLYSCOTCH Real Estate Demo

Premium responsive real estate website built with Next.js + TypeScript.

## Included
- Luxury black / gold visual system based on the supplied HOLLYSCOTCH logo
- Responsive desktop, tablet and mobile navigation
- Premium homepage and hero property search
- Properties directory with live client-side filters
- Individual property detail pages
- Services, About and Contact pages
- WhatsApp enquiry flows connected to **08134335308**
- Inspection enquiry forms that open WhatsApp with a pre-filled message
- Floating WhatsApp CTA
- SEO metadata and production-ready Next.js structure

## Run locally (Windows CMD)
```cmd
npm install
npm run dev
```
Open: http://localhost:3000

## Production verification
```cmd
npx tsc --noEmit
npm run build
```

## Notes
The demo property listings and imagery are presentation content. Replace them with the client's real inventory before a public launch.
